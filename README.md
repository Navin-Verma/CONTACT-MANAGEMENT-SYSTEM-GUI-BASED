# CONTACT MANAGEMENT SYSTEM

A GUI-based Contact Management System developed using Python and Tkinter. The application allows users to efficiently manage contacts through an interactive graphical interface with support for adding, searching, updating, deleting, saving, and loading contact records.
---

## Features

- Add new contacts
- Search existing contacts
- Update contact information
- Delete contacts
- Save contacts to a text file
- Load contacts from a text file
- Input validation for email addresses
- Phone number validation
- Interactive GUI using Tkinter
- Contact display using Treeview widget
---
